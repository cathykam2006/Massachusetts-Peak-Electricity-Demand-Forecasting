# Deploying to Streamlit

## 1. Folder structure

Arrange your project like this before deploying:

```
your-repo/
├── app.py
├── train_and_save.py
├── requirements.txt
├── .gitignore
├── data/
│   ├── isone_full_dataset.csv       (generated by train_and_save.py)
│   ├── model_comparison.csv         (generated)
│   ├── test_predictions.csv         (generated)
│   └── shap_values_test.npy         (generated)
└── models/
    ├── xgb_model.pkl                (generated)
    ├── lgb_model.pkl                (generated)
    └── feature_cols.pkl             (generated)
```

## 2. Generate the artifacts locally, once

```bash
pip install -r requirements.txt
export EIA_API_KEY="your_real_key_here"
python train_and_save.py
```

This populates `data/` and `models/`. Confirm both folders have files in them before continuing.

## 3. Add a `.gitignore`

Create a `.gitignore` file with at minimum:

```
.streamlit/secrets.toml
__pycache__/
*.pyc
```

Do **not** gitignore `data/` or `models/` — the app needs those files to exist in the
deployed repo, since Streamlit Cloud only runs `app.py`, not `train_and_save.py`.

## 4. Push to GitHub

```bash
git init
git add .
git commit -m "Initial commit: MA peak demand forecasting app"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
```

Make sure the repo is public (or connected via Streamlit Cloud's GitHub integration
if private).

## 5. Deploy on Streamlit Community Cloud

1. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub.
2. Click **New app**.
3. Select your repository, branch (`main`), and set the main file path to `app.py`.
4. Click **Deploy**.

Streamlit Cloud will install everything in `requirements.txt` and launch the app. You'll
get a public URL like `https://your-app-name.streamlit.app`.

## 6. (Optional) If you later add a "live refresh" feature

If you extend the app to pull fresh data from the EIA API at runtime (rather than only
serving the pre-trained snapshot), don't hardcode the API key in `app.py`. Instead:

1. In the Streamlit Cloud dashboard, go to your app → **Settings** → **Secrets**.
2. Add:
   ```toml
   EIA_API_KEY = "your_real_key_here"
   ```
3. In `app.py`, access it with:
   ```python
   import streamlit as st
   api_key = st.secrets["EIA_API_KEY"]
   ```

This keeps the key out of your public GitHub repo entirely.

## Notes

- The app as built **does not retrain models live** — it loads the `.pkl` files produced
  by `train_and_save.py`. This is intentional: retraining XGBoost/LightGBM/SHAP on every
  page interaction would make the app slow and could hit Streamlit Cloud's resource limits.
- If you want the dataset to stay current (e.g., refresh monthly with new EIA data), re-run
  `train_and_save.py` locally on a schedule and push the updated `data/`/`models/` files —
  Streamlit Cloud auto-redeploys on every push to the connected branch.
- SARIMAX is intentionally excluded from `train_and_save.py` and the live app, since it's
  slow to fit and performed worse than the baseline in this project — it's documented in
  the notebooks but not part of the interactive comparison shown to app users. Add it back
  in if you want it in the app's model-comparison table.
